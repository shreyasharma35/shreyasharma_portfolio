## ✨ About the Project

Welcome to my interactive personal portfolio!

This project explores a creative approach to portfolio design by combining AI-generated visual assets with frontend development. The centerpiece is an animated portrait created using Google Flow and integrated into an interactive website.

As visitors move their cursor across the screen, the portrait's eyes respond to the cursor's direction, creating an engaging and personalized browsing experience.

Designed with a bold red background, a minimal interface, and carefully aligned facial images, this portfolio reflects my interest in experimenting with AI tools and building distinctive web experiences.

## 🚀 Features

- ❤️ **Interactive AI Portrait** — An animated personal portrait created with Google Flow.
- 👀 **Cursor-Responsive Eyes** — The eyes follow cursor movement for a dynamic visual experience.
- ↔️ **Directional Facial Expressions** — Directional image states help the portrait respond to movement.
- 🔴 **Bold Visual Identity** — A rich red background (`#a30f16`) complements the portrait.
- 🖼️ **Seamless Portrait Integration** — The image is designed to appear directly on the background without an unnecessary card or square container.
- ✨ **Dynamic Visual Interaction** — JavaScript handles cursor movement and interactive image behavior.
- 💻 **Responsive Web Experience** — Built with the goal of maintaining a consistent visual presentation across supported screen sizes and browsers.
- 🌐 **Live Deployment** — Published online using Netlify.

## 🎯 Project Objective

The goal of this project is to explore how AI-generated imagery can be combined with frontend programming to create a more engaging personal portfolio.

Rather than using a conventional static hero image, I experimented with cursor-responsive visual interactions to make the landing page feel more personal and memorable.

This project represents my interest in:

- AI-assisted creative workflows.
- Interactive frontend development.
- JavaScript-based user interactions.
- Visual design and user experience.
- Experimentation, debugging, and continuous learning.

## 🧠 Key Learning Outcomes

Through this project, I explored:

- Integrating AI-generated visual assets into a website.
- Using JavaScript to track cursor movement.
- Implementing directional image changes for interactive visual effects.
- Using CSS positioning and alignment to create a seamless portrait presentation.
- Debugging image-loading and rendering issues.
- Refining the user experience through iterative testing.
- Using AI-assisted development tools to improve and troubleshoot a frontend project.
- Deploying a website using Netlify and managing source code with GitHub.
